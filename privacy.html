Privacy Policy

Casino Royale is a free, fictional-money casino game that runs entirely in your browser. This page explains, in plain language, what it does and does not do with information about you.

Last updated · 17 September 2026

The short version

  • You never need an account. There is nothing to sign up for, nothing to buy, and no real money anywhere in the game.
  • Your run is stored on your own device (your browser's local storage) so the game can pick up where you left off. It is not uploaded anywhere unless you deliberately switch on the optional Google backup described below.
  • There is no game server, no analytics, no advertising and no tracking. The person who made this game cannot see you, your run, or anything about you.
  • One optional exception: if you press "Sign in with Google", your save is copied to a hidden folder in your own Google Drive. It goes straight from your browser to Google — never to us — and you can delete it or revoke access at any moment.

1Who runs this game

Casino Royale is a free, open-source hobby project (also titled Gamble Casino). There is no company behind it, no employees, no advertising and no business model. That is not a marketing claim but a description of the architecture: there is simply nowhere for your data to be sent, because there is no server belonging to this project at all.

Source code, bug reports and contact: github.com/chrislegend95/Casino-Royale.

2What is stored on your device

The game is local-first: everything it knows about your run lives in your browser's localStorage on the device you are playing on, and never leaves it unless you choose the optional cloud backup. That data is:

Stored valueWhat it holds
casino-royale.save.v1Your run: balance, level and XP, purchased perks, per-machine statistics, play history, the machine and bet you were last on, and loan / auto-play settings.
casino-royale.sound.v1

casino-royale.device.v1Only created if you use the cloud backup: a random ID generated on your device, plus a friendly name for it (for example "Chrome on Windows"), used solely to label which device last wrote your backup file.
casino-royale.cloud.session.v1Only if you sign in with Google: your Google account name, email address and avatar URL, and a short-lived access token. See section 4.1 for exactly why, and how to remove it.
casino-royale.cloud.deferred.v1Only if you sign in: a tiny flag so the game remembers that a backup still needs to be pushed.

All of it is fictional game data. None of it identifies you by itself. You can erase every one of these values at any time by clearing site data for this page in your browser's settings — the game will simply start a fresh run.

4The one optional exception: cloud save

At the top of the game there is a "Sign in with Google" button. It exists only so that a run can survive a wiped browser or move to another computer. It is completely optional — if you never touch it, nothing about the game changes and no information ever leaves your device.

4.1If you do use it

  • What it asks Google for. Two permissions: drive.appdata (create, read, update and delete files that this app created in a hidden app folder of your Drive) and userinfo.email (your email address, so the panel can show which account is signed in). Nothing more — no access to the rest of your Drive, your Gmail, your contacts, or any other Google service.
  • Where it goes. The page talks directly to Google — accounts.google.com to sign in and www.googleapis.com for Drive. There is no intermediary server, and no save data is ever sent to the author of this game.
  • What is stored. One small JSON file (casino-royale-save.json) containing your run — the same fictional game data listed in section 2 — is written to the hidden app data folder of your own Google Drive. That folder does not appear in your normal Drive file list.
  • Who can read it. You, and anyone who already has full access to your Google account. Not the author of the game, not other players, not any third party.
  • How long it lasts. Until you delete it. It is not on a timer and it does not expire.
  • How to undo it. In the same panel, DELETE CLOUD SAVE removes the file from your Drive, and SIGN OUT ends the session and erases the locally stored Google account details and token from your browser. Independently of the game, you can revoke this app's access at myaccount.google.com/permissions, which invalidates the access token immediately.
Signed in or not, the local save keeps working. The cloud copy is a mirror, never a dependency — losing the connection, signing out, or deleting the cloud file cannot lose the run you have on this computer.

5Manual save files (no account at all)

The same panel offers DOWNLOAD SAVE FILE and LOAD SAVE FILE, which write and read a small .json backup on your own device. This works signed out and involves no network at all; a file you download is entirely yours to keep or delete.

6Hosting and third parties

  • Hosting. The pages are static files served by GitHub Pages. Like any web host, GitHub may record standard technical request data such as your IP address and browser user agent in its server logs. That is GitHub's processing, under GitHub's privacy statement, and is not visible to the game or its author.
  • Fonts. The page loads two typefaces from Google Fonts, which means your browser makes a request to Google's font servers. Google Fonts does not set cookies for this. If you block it (an ad-blocker will do), the game simply falls back to system fonts and works exactly the same.
  • Google sign-in (optional, section 4). Uses Google Identity Services and the Google Drive API. What Google does with your account data is governed by Google's Privacy Policy.
  • Perchance. The game is also published as a generator on perchance.org. There, the page is embedded in an iframe served by Perchance, and Perchance — a separate service with its own privacy policy — may collect basic technical information such as your IP address. The cloud save feature is switched off in the Perchance copy, so the game itself sends nothing anywhere.

7Children

Casino Royale is a fictional gambling-themed toy and is not directed at children. It does not knowingly collect personal information from anyone, including children — there is nothing collected from a player who does not deliberately sign in, and Google accounts carry their own age requirements. No real money, real gambling, real betting or prizes are involved at any point.

8Changes to this policy

If the game ever changes in a way that affects this policy — for example, a new feature that would send data somewhere — this page will be updated and the date at the top of the page changed. Because the project is open source, the complete history of this page is also visible in the project's git repository.

9Contact and your data
